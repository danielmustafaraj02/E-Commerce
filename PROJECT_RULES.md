# PERLA MURANO GLASS — PROJECT RULES

Website:
https://perlamuranoglass.com

Brand:
Perla Murano Glass

Business:
Handmade Murano glass jewelry.

Location:
Murano / Venice, Italy.

PRIMARY OBJECTIVE

Create a premium, trustworthy, high-converting ecommerce brand
that is technically excellent, SEO-ready, accessible, fast,
mobile-first and maintainable.

DESIGN DIRECTION

Contemporary Italian luxury
+
Murano glass craftsmanship
+
Venetian atelier
+
Editorial jewelry photography.

The website should feel:

- sophisticated
- tactile
- artistic
- calm
- premium
- authentic
- distinctly Italian

Avoid:

- generic AI website aesthetics
- purple gradients
- generic SaaS layouts
- excessive rounded cards
- excessive shadows
- unnecessary glassmorphism
- decorative blobs
- excessive animation
- stock-looking imagery
- fake luxury language

BRAND PRINCIPLE

The glass and craftsmanship are the visual identity.

Photography, typography, whitespace and composition should carry
the brand before decorative UI effects.

DO NOT INVENT FACTS.

Never invent:

- artisans
- workshops
- certifications
- awards
- press coverage
- reviews
- customer testimonials
- materials
- production techniques
- business history
- shipping promises
- guarantees

If required information is missing:

WRITE:
NEEDS INPUT

instead of inventing it.

SEO PRINCIPLES

Every indexable page must have:

- unique title
- useful meta description
- one clear H1
- logical headings
- canonical URL
- internal links
- descriptive images
- appropriate structured data
- meaningful content

Do not keyword stuff.

Do not create thin SEO pages.

Do not generate hundreds of pages only to target keywords.

ECOMMERCE PRINCIPLES

Products must be easy to:

- discover
- understand
- trust
- compare
- purchase

Product information must be accurate.

Never invent ratings or reviews.

Never create fake scarcity.

Never create fake urgency.

ACCESSIBILITY

Target WCAG 2.2 AA practices.

Everything important must work with:

- keyboard
- touch
- screen readers
- zoom
- reduced motion

PERFORMANCE

Measure before optimizing.

Optimize actual bottlenecks.

Do not claim improved Core Web Vitals without measurement.

IMAGES

Use:

- responsive images
- correct dimensions
- WebP/AVIF where appropriate
- lazy loading below fold
- priority loading for the LCP image

SEO STRUCTURED DATA

Product pages should use accurate Product / Offer structured data
where eligible.

Structured data must match visible page information.

INTERNATIONAL SEO

Prepare architecture for:

/en/
/it/
/de/
/fr/

Do not launch languages until content quality is sufficient.

ANALYTICS

Track:

view_item
select_item
add_to_cart
view_cart
begin_checkout
purchase
newsletter_signup
search
gift_finder_start
gift_finder_complete

QUALITY RULE

No task is finished because the code "looks right."

Every major change must be:

1. implemented
2. tested
3. audited
4. fixed
5. audited again
6. documented
