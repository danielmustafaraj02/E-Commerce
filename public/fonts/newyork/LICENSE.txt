WHAT THE PACKAGE CONTAINS
  NewYork.otf only. The archive ships NO licence document, so the statement
  above (from the distributor's page) is the only licence evidence there is.

TWO THINGS TO CHECK BEFORE RELYING ON THIS COMMERCIALLY
  1. The font's OS/2 fsType flag is 4 ("Preview & Print embedding"). Read
     strictly, that permission bit does not cover web-font embedding, and it
     disagrees with the distributor's "Web Font: Yes".
  2. "100% Free" is not a named licence (it is not OFL, not MIT), and the
     copyright string reserves all rights. For a commercial storefront, get
     the author's written confirmation for web use.

  Nothing was subset, renamed or re-outlined. One real weight (400, upright);
  the font has no bold and no italic, so none is ever synthesised.
